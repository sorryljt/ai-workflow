# todolist demo 验收记录

项目：Vite 8 + React 19 + TS + Vitest + RTL，localStorage 持久化。工具：Claude Code CLI。五个需求按 PRD 顺序跑，中间随工作流迭代升级了 4 次。

## 结果

| 需求 | 档位 | plan | code | review | check | ship | 合计 | 人工介入 |
|------|------|------|------|--------|-------|------|------|---------|
| F4 输入校验 | M | — | — | 3 轮 | 1 | — | ~30m | 确认 plan；补子进程权限（工作流缺陷，已修） |
| F1 编辑待办 | M | 10m | 3m | 5+3+5m | 3+4m | 3m | 43m | 确认 plan；决定修一条 SUGGESTED |
| F2 全选 | S | — | 3m | 2m | 2m | 1m | 8m | 无 |
| F8 优先级 | L | 2m | 6m | 8+4m | 5m | 2m | 27m | 确认 plan；中途打断续接 |
| F5 搜索过滤 | M | 2m | 5m | 6m | 3m | 2m | 18m | 确认 plan |

- review 共 10 轮，独立进程抓到 3 个真实 BLOCKING（F1 编辑已完成项误判重复；F8 段标题样式；F4 为权限问题非代码缺陷），全部由 AI 自行修复并复审通过。
- check 共 6 轮，0 ❌；每轮 1～4 条 👀 待人工，均为 jsdom 测不到的渲染 / 输入法 / 拖拽表现。
- 测试从 0 增至 92 个，src/ 在所有审查轮次中未被审查者要求重写。
- 续接：F8 在 review 阶段打断、手工改代码后 `/viktor-flow` 从复审续上；新会话空跑 `/viktor-flow` 正确提示无候选。
- 知识库：迁移 11 条旧条目为单文件，F5 起按新格式写入并被 plan 阶段 lookup 命中。

## 验证过程中修掉的工作流问题

| 问题 | 修复 |
|------|------|
| `claude -p` 子进程跑不了检查命令，两轮 review 白跑 | init 写入 permissions.allow；命令无法执行返回 `result: error` → 退出码 2，不消耗复审轮次 |
| 仓库零 commit 时 spawn 拿不到 diff | init 检查基线 commit |
| check 无浏览器工具仍尝试起 dev server | prompt 禁止 |
| 节点输出散文多、表格在代码块里显示为源码 | 统一纯文本卡片；待确认卡 / 需要处理卡 / 节点完成卡；报告表格不放代码块 |
| "停车"措辞、"你可以 / 继续"歧义、卡内举例 | 去掉；最后一行固定一句话 |
| 判档理由啰嗦 | 一行声明 |
| 待人工确认里混入决策项 | ship 规则：只放验证项 |
| 知识库整目录读，随需求线性增长 | 一条一文件 + 索引 + `knowledge.sh lookup` 按范围检索 |
| S 档判定偏松（F2 自行定了口径） | 判据改为"有无需要人拍板的取舍" |
